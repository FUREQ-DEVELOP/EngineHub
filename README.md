# EngineHub

GameEngineおよびEngineEditorの利用環境を管理するソフトウェアです。

## 開発目標

- ゲームプロジェクトの作成と管理
- エンジンバージョンの管理
- SDKおよびエディターのインストール
- プロジェクト単位のバージョン固定
- モジュールの導入と管理
- エディターの起動

## 責務

エンジン利用者の制作環境を管理します。

Organization全体の共同開発管理ポータルとは別の製品です。

## 管理担当

Engine-Team

## 利用方法

- 作業は `main` からブランチを作成し、Pull Requestで提案してください。

- 変更の責務: EngineHub。担当Team: `Engine-Team`。
- 依存関係や開発状況は [DevelopmentDocs](https://github.com/FUREQ-DEVELOP/DevelopmentDocs) を参照してください。
